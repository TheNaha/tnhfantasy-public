# Backend Documentation

The backend of TNHComfy (`tnhcomfy-backend`) is built with **FastAPI** (Python), serving as the core engine for job queuing, orchestration, and communication between the frontend and serverless inference providers.

## Key Technologies
- **FastAPI:** High-performance web framework for APIs.
- **SQLite:** Lightweight local database for job tracking and state management (`backend_v2/data/comfy.db`).
- **WebSockets:** Real-time bi-directional communication with the frontend for job status updates.
- **HTTPX:** Asynchronous HTTP client used for non-blocking requests to external providers.
- **Structlog:** Structured logging for better debugging and observability.

## Architecture

The backend consists of several key modules:
1. **API Routes (`backend_v2/api/routes`):** Defines the REST endpoints for jobs, models, configurations, and WebSockets.
2. **Core Services (`backend_v2/core`):** Contains the business logic, including job queuing, event publishing, and worker interaction.
3. **Infrastructure (`backend_v2/infrastructure`):** Handles database connections, asynchronous HTTP clients (`http_client.py`), and caching mechanisms.

## Data Storage Strategy
- **Relational Data:** Information like jobs, models, and application settings are stored in `comfy.db` (SQLite).
- **Files:** Output images generated by ComfyUI are stored locally on the filesystem. A custom `GalleryIndexer` is used to maintain a highly performant `filename_index` (mapping filenames to absolute paths) to enable O(1) lookups for endpoints like `serve_thumbnail`, avoiding recursive filesystem scans.
- **Transient Data:** The backend does *not* permanently store large checkpoints. This ensures a lightweight and responsive server.

## Event Loop and Async Operations
- The backend relies heavily on `asyncio` to prevent blocking operations, specifically when fetching data from external APIs or performing database queries.
- **Synchronous Calls:** Any synchronous calls (like `requests.get()`) are generally avoided or refactored into `httpx.AsyncClient` calls.

## Development Setup
1. Ensure Python 3.9+ is installed.
2. Navigate to `backend_v2`:
   ```bash
   cd backend_v2
   python3 -m venv venv
   source venv/bin/activate
   pip install -r requirements.txt
   ```
3. Copy `.env.example` to `.env` and fill in necessary tokens (HF_TOKEN, CIVITAI_TOKEN).
4. Run the server:
   ```bash
   uvicorn api.main:app --reload
   ```

## Background Tasks
The backend utilizes background tasks (e.g., polling `gallery_indexer` for output files) after a worker finishes a job, ensuring a smooth transition of state to `COMPLETED` and preventing UI race conditions where the frontend eagerly attempts to fetch unindexed thumbnails.
