## Critical bugs

### C1 — `_capability_cache` definition deleted at HEAD; rotation silently stopped invalidating [x]
**Location:** `backend_v2/services/load_balancer.py` (definition gone), `services/engines/engine_factory.py:1052`
**Evidence:** commit `27d74c3c` removed the `_capability_cache` / `_CAPABILITY_CACHE_TTL_SECONDS` block (its message says "Add TTLCache … to prevent unbounded cache growth" — it deleted the block instead of converting it) while 8 call sites remained → ruff F821 ×8. Because `invalidate_engine` imports it inside a bare `try/except Exception: pass` (engine_factory.py:1052-1064), the `ImportError` was **swallowed** and provider rotation silently stopped clearing *every* health-cache key too — the M1/M5 fix was dead on arrival.
**Fix applied:** restored as a bounded, env-configurable `TTLCache` (`COMFY_PROVIDER_CAPABILITY_CACHE_TTL_SECONDS`/`_MAX_ENTRIES`, TTL 60s, max 128), added `_capability_cache.clear()` to the runtime-reset path, and replaced the vacuous `test_capability_cache_unbounded` placeholder with two real regression tests (`tests/test_critical_bugs.py`).

### FP-1 — Every error frame of the Beam LLM/TTS websocket is broken (`_reject` never awaits) [ ]
**Location:** `deployables/beam/llm_tts_app.py:154-159`, call sites :207,210,217,222,230,266,646,649,654,660,673
**Evidence:** `def _reject(...) -> None:` is sync; body is `websocket.send_text(...)` without `await`. `send_text` is async → coroutine discarded → `await _reject(...)` = `await None` → `TypeError`. Verified by reading definition + all 11 call sites; `test_deployable_contract.py` asserts names/routes only, so it cannot catch this. `ruff check deployables/` clean (F rules miss it).
**Risk:** every error path on `WS /llm` and `WS /tts` (auth rejection, cold-start "still loading" retryable, unknown model, upstream failure) raises instead of sending `{"event":"failed"}`; the backend receive loop waits for `completed|failed|cancelled` and loses the retryable signal.
**Fix:** `async def _reject` + `await websocket.send_text(...)`; add an AST/behavior test.
