### Baseline regression found (now fixed)
`test_job_diagnostics.py::TestStaleRecovery::test_queue_manager_recover_reports_summary` FAILED. Root cause: `services/job_queue.py` `recover()`/`start()` used the module-level `_DB_CLAIMS_ENABLED` constant (computed at import time from `database_url`, `postgresql` in Docker) instead of `_db_claims_enabled()` (checks real engine dialect at call time). Tests override the engine to SQLite, so `recover()` took the `db_claims` branch which never populated the in-memory queues the test inspects, and reported `mode="db_claims"` instead of `"in_memory"`. Fixed in commit ec653d93.

## Critical Bugs

**Severity:** High — caused `test_queue_manager_recover_reports_summary` failure.
