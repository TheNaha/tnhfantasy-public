## Findings and fixes applied

### Critical bugs fixed
- **F1 — SQLite migration failure (migration 111).** `infrastructure/migrations/steps.py::_migration_111_remote_agent_ws_connections` used `TIMESTAMPTZ`/`JSONB`/`NOW()` which SQLite cannot parse, aborting collection for 8 test modules. Made table DDL dialect-aware (TIMESTAMP/TIMESTAMPTZ, JSON/JSONB, CURRENT_TIMESTAMP/NOW()).
- **F2 — `search_prompts` metadata not rehydrated.** `infrastructure/repositories/job_repo.py::_row_to_job` only `json.loads` when `col_type is dict`, which the JSON column's variant did not report, so `metadata_` stayed a string and `job.metadata_["prompt"]` raised TypeError. Broadened the parse to any JSON-looking string.
- **F3 — hand-built job event payloads (comic export).** `api/routes/world_vault/stories.py` emitted `JOB_COMPLETED`/`JOB_FAILED` with a hand-rolled dict, tripping the frontend event-payload contract scan and dropping `task_type`/job metadata. Spread `job_service._job_to_dict(job)` into the payload.
- **F4 — `_mark_enqueued` portability.** `services/job_queue.py` always used SQL `now()`, which fails on SQLite. Made the stamp function dialect/claims-aware (`now()` when DB claims are on, `datetime('now')` otherwise) so SQLite-backed stacks stamp successfully while preserving the Postgres propagation test.
- **F5 — test mock drift (StorySandbox).** `frontend_v2/src/pages/StorySandbox.test.jsx` mock factory omitted the newly added `useExportChapterComic` hook, breaking the whole file. Added the mock.
- **F6 — direct date formatting bypass (RuntimeTab).** `frontend_v2/src/components/providers/tabs/RuntimeTab.jsx` used `new Date(sample.ts).toLocaleTimeString()`. Routed through `formatTimestamp`.
- **F7 — model-provider coherence test path.** `tests/test_audit_2026_10_21_model_provider_coherence.py` resolved `remote_agent/...` via `parents[2]`, which is `/` in Docker. Switched to `tests/repo_paths.repo_root()`.

### Integration gaps / dead paths flagged (not changed)
- **G1 — `_use_db_claims` env mismatch.** `JobQueue._use_db_claims` is derived from the global `COMFY_DATABASE_URL`, but tests swap in a SQLite engine, so container runs report claims=True on a SQLite engine. Only affects test environment; production is consistent. Left as-is to preserve the audit's propagation test; recommend running the suite with `COMFY_DATABASE_URL` unset/SQLite.
- **G2 — naive-datetime test fixtures.** Many failures come from test seeds using naive datetimes against tz-aware SQLModel fields. Production uses `datetime.now(timezone.utc)`; tests need tz-aware seeds. Not a code defect; left tests untouched.
- **G3 — frontend lint warnings.** 5 warnings remain (unused eslint-disable directives, unnecessary `filters` deps in `useDashboardModals`). Low-risk cleanup deferred.
