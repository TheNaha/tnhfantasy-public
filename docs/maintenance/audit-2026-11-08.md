Searched production code for common bug classes; all hits are benign or intentional:

- `except BaseException:` in `api/routes/settings.py` — atomic-write cleanup (mkstep + fsync + os.replace, catch-all, clean temp file, re-raise). Correct; matches the pattern blessed in prior audits.

- `addEventListener` / `setInterval` / `setTimeout` in frontend — all paired with cleanup in `useEffect` returns. No leaks.
- `settingsStore.js` — legitimate localStorage-persisted UI preferences, not server data (documented server-config mirror contract). No Zustand/React-Query boundary violation.

- `f"..."` in SQL text — identifiers only; values use bound parameters. No injection risk.
- No `TODO`/`FIXME`/`HACK`/`XXX` markers in production code.
