## Critical bugs fixed

### B1 — Timezone (offset-naive vs aware) mismatches
**Locations:**
- `backend_v2/services/provider_telemetry_service.py:494` — `warm_until = completed_at + ...` where `completed_at` (from DB, naive) was subtracted from aware `_utcnow()`. Fixed with `as_utc`.
- `backend_v2/services/job_boot_metrics.py:82` — `datetime.now(timezone.utc) - started_at`. Fixed with `as_utc`.
- `backend_v2/infrastructure/worker_registry.py:271` — `datetime.now(timezone.utc) - worker.last_heartbeat`. Fixed with `as_utc`.
- `backend_v2/services/job_service.py:132` (`as_utc`) made robust to non-datetime inputs so mock-based tests keep working.

**Root cause:** DB columns are naive; code mixed aware `datetime.now(timezone.utc)`. Centralized on existing `as_utc` helper.

### B2 — Inconsistent event payload key (`error` vs `error_message`)
**Location:** `backend_v2/services/in_process_reconciliation.py:1069` — one `MODEL_SYNC_FAILED` emit used `error=str(exc)` while the other used `error_message=str(exc)`. Unified to `error_message`.

### B3 — Mask upload required field returned 422 instead of 400
**Location:** `backend_v2/api/routes/files.py:1975` — `MaskUploadRequest.mask_data: str` (required) made FastAPI return 422 before reaching the `ValidationError` branch. Made optional with default `None` so the existing "mask_data is required" 400 path runs.

### B4 — Versionless models dropped from file listing
**Location:** `backend_v2/api/routes/files.py:1426` — when `versions` was empty, `target_versions` was empty and the model was silently skipped, so `trained_words` (and the entry) never serialized. Emit a single `None`-version entry in that case.
