# TNHComfy Vision Document

TNHComfy has evolved from a simple ComfyUI image generator wrapper into a **Comprehensive AI Fantasy Engine**. It integrates three core pillars:
1. **Image Generation**: Using serverless providers (Modal, Beam) wrapped around ComfyUI.
2. **Roleplay Chatbots**: Stateful, SillyTavern-style character chats with autonomous agentic workflows.
3. **Story Sandbox**: An AI Dungeon-style interactive document editor for crafting stories.

## Massive Future Frontiers

We are building towards these massive future frontiers:
1. **Autobiographical Memory (RAG)**: Indexing all past chat messages and story beats into `pgvector` so the LLM can perfectly recall distant events across long campaigns.
2. **Visual Novel / Comic Compiler**: An exporter that reads a Story Sandbox chapter and automatically generates images, panels, and speech bubbles to output a formatted web-comic or PDF.
3. **Relationship Graph UI**: A living, node-based wiki (similar to Obsidian) visualizing the connections between Characters, Locations, and Lorebooks.
4. **Agentic Idle Simulation**: Background cron jobs where characters autonomously live, craft, and interact while the user is offline, summarizing their actions upon return. 
5. **Video / Animation**: Expanding the ComfyUI payload to support AnimateDiff for looping character avatars.
